# 用户操作指南

## 登录与授权

1. 打开平台，输入账号、密码和算术验证码。
2. 若部署方已开启自助注册，“登录”页会显示“申请平台账号”。选择邮箱或手机作为已验证联系方式，先完成图形验证码，再填写 6 位验证码；验证码 5 分钟内有效且只能使用一次。未选择渠道的联系方式不会被保存或占用。
3. 申请提交后账号保持停用并仅有访客角色。管理员在“用户与权限 → 注册审核”中复核资料，分配角色、直接数据域和部门后批准，账号才可登录；驳回理由通过所选通知渠道发送。本机 `SIMULATED` 仅用于验收，不代表真实邮件/短信已开通。
4. 若部署方关闭自助注册，页面不会显示入口，发码和注册 API 也会被后端拒绝，账号由管理员统一创建。
5. 全新部署的引导管理员可使用部署方配置的初始密码直接登录；应在进入系统后尽快到个人中心修改密码。
6. 菜单和路由由权限控制，数据内容还会按项目/部门/产品线数据域过滤。没有工作台权限时，系统会转到首个可访问模块或个人中心。
7. 点击右上角头像进入“个人中心”，可查看角色、部门和数据域，修改姓名、邮箱、手机号或密码。

## 模板与数据集

1. 在“模板中心”创建章节和字段定义，字段 key 使用英文字母开头，可配置类型、必填、长度、数值范围、日期和正则约束。
2. 模板详情显示当前状态和完整版本历史。草稿可编辑；提交后进入待审核并冻结；创建者不能审核自己的模板；审核通过后发布且不可原地修改，需“复制为新草稿”产生新版本路线。
3. 在“数据资产”可选择一个已经独立审核通过的完整模板创建数据集，系统复制该模板版本的全部章节、字段和约束；模板片段、草稿和待审核模板不能绑定。也可以创建明确标识的自定义结构。
4. 空且没有附件的数据集可调整数据域；已经包含记录或附件的数据集会冻结数据域，已有记录时还会冻结字段结构并禁止删除。模板和数据集均可收藏或取消收藏。
5. 进入记录页可在线录入或导入 CSV、JSON、XLSX。导入采用逐行处理：合法行落库，错误行保留行号、原始值和原因；在导入作业中查看结果。
6. 导出前可选择 CSV、JSON、XLSX 和一个或多个字段。系统会中和电子表格公式前缀并记录导出审计。

## 审核与发布

1. 记录初始为“草稿”，创建者点击“提交审核”。
2. 审核员不能审核自己创建的记录；审核/发布时必须再次输入当前密码。
3. 驳回后先做受控更正、填写原因并生成新版本，才能重新提交。
4. 审核通过后由有发布权限的人员发布。已通过或已发布记录不能原地修改/删除。
5. 普通读者只能看到已发布记录或自己创建的未发布记录；审核员和管理员可查看待处理内容。

## 追溯、设备、文件和审计

- “全链路追溯”选择实体、方向和深度查看材料—工艺—批次—产品—检测关系。
- “设备与采集”登记设备后可查看测量；连接密码等敏感配置只以加密形式保存，不在页面回显。
- “附件中心”先选择有权访问的业务对象，再上传、下载或删除。图片/纯文本可安全预览；PDF、HTML、SVG 和工程文件使用下载方式处理。
- “审计中心”查询关键操作；管理员可执行审计链验证。验证失败应立即停止相关发布操作并联系安全/运维人员。

## 外部系统集成

1. 在“系统集成”创建 MES/PLM/ERP 等配置，填写稳定的系统编码、信任域/实体类型、精确来源 IP 白名单和字段映射。系统编码一旦产生作业便不能修改。
2. HMAC 模式使用“生成 256 位密钥”或录入不少于 32 UTF-8 字节的随机密钥；调用方必须按 API 指南的 `RDP-HMAC-V1` 规范签名，不能复用旧版点号拼接算法或把签名跨系统/跨路径使用。
3. OAuth2 模式必须区分两个身份：“平台自省客户端”是本平台访问令牌自省端的 client_id/secret；“外部调用方 AppID”是 token 中必须匹配的来源 client_id。issuer、audience、scope、自省 URL 与来源 AppID 均必填，同一 issuer 下的来源 AppID 不能绑定多个系统。
4. Webhook 认证成功后先返回 202 并持久化作业，后台再执行映射、信任裁决和交付。失败作业按退避计划重试，耗尽后进入“死信/人工复核”；人工重放需要二级确认和原因。
5. 轮换当前密钥不会改写已经接收的待交付作业：旧作业使用其加密快照重试，完成、跳过或明确终止后即清除快照。生产轮换前仍应检查死信、目标幂等能力和厂商切换窗口。
6. 页面中的本机模拟 HTTP/OAuth 证据不代表真实厂商已联调。正式启用前，运维必须配置允许的自省/交付主机、受信 DNS 和出口防火墙，并在隔离环境完成调用、重放、503、超时及撤权演练。
