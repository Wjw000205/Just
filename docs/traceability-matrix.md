## 更新约定

- “需求状态”只描述源文档是否足够明确；代码实现状态建议使用 `未开始 / 开发中 / 已实现 / 已测试 / 已验收 / 阻塞` 六态另列。
- 每个实现 PR/提交至少引用一个矩阵 ID；每个 P0/P1 ID 至少关联一个自动测试或明确的人工验收用例。
- 对所有 `TBD` 项，测试可以验证安全默认值和模拟契约，但最终状态不能标记为“已验收”。
