# 实现与验收状态

> 日期：2026-08-12。这里描述当前 V33 代码与 BAK-002 恢复工具状态；需求原文是否明确仍以 `traceability-matrix.md` 为准。

## 已实现并通过当前自动/独立测试

- 认证、首次改密、刷新单次消费、撤销、登录锁定、RBAC、多角色、数据域；匿名认证具有读取前 16KB 请求体上限、字段长度边界、IP/全局 Redis 原子限流和脱敏缓存键。
- 模板可视化章节/字段设计、版本快照与历史、发布/审核职责分离、待审核/已发布冻结、收藏和数据集模板绑定。
- 数据集从已发布完整模板复制 content 与 JSON Schema 全部字段约束、自定义字段设计、typed options、空集编辑/删除、收藏，以及记录页按字段导出。
- 数据集元数据与记录创建采用数据库互斥协议；记录/附件存在时冻结数据域，文件读取重新复核当前业务对象的数据域。
- 可配置且默认关闭的自助注册：邮箱/手机 6 位 Redis 一次性验证码、本机模拟通知、待审账号、管理员二级确认审核、原子角色/数据域/部门授权与启用；已验证目标使用 HMAC 摘要固化，未验证的另一联系方式不入库。
- 个人资料页面、权限路由兜底和全局搜索结果跳转。
- 动态记录校验、同键并发安全的幂等写入、CORRECTING/DELETING fencing、受控删除、带租约的 Outbox、记录工作流和可独立验真的电子签名。
- CSV/JSON/XLSX 逐行导入、错误作业；三格式流式导出、字段选择、敏感字段脱敏、附件清单与实体 ZIP 包。
- 正向/反向/双向 SVG 追溯链、节点原始记录与来源、附件和不可变审计证据展开、逐节点数据域裁剪；设备登记和测量幂等、GridFS 附件与跨库存储对账；大文件分片、断点续传、整体/分片 SHA-256、Range/416 下载和过期清理。
- 集成配置、映射/清洗、信任源裁决、异步作业、游标、幂等交付、退避死信和对账；外部写入支持绑定系统/路径的 `RDP-HMAC-V1` 与 OAuth2 RFC 7662，自省强制独立来源 client_id、issuer、audience、scope、exp/nbf、精确 IP 和主机白名单，V32 HTTP 作业保存最小化凭据快照并在终态擦除；V33 对升级前 HMAC 密钥先失败关闭再解密验强，弱/损坏凭据自动停用并进入可审计轮换状态。
- 追加写入审计、HMAC 链验证、历史密钥验证、签名/测量不可变触发器。
- 按用户、部门和角色配置的数据集/数据域选择性共享，READ/EXPORT/DOWNLOAD 分离、到期、撤销和停用资源即时失效。
- 中文全文 GIN 检索、服务端安全高亮、用户隔离的 Redis 搜索历史和热门建议。
- PUBLISHED 数据记录的重要性、保留策略/例外、PG+Mongo+GridFS 归档清单、摘要校验、恢复、陈旧转换回收和持久清理。
- 停写维护窗口下的 PostgreSQL + MongoDB/GridFS 同点恢复：非静止状态拒绝、原生 dump、Flyway/关键计数/附件引用与 GridFS 分块清单、逐文件 SHA-256、版本化 HMAC manifest、恢复前原生归档预检、精确 backupId 确认和恢复后自动对账；隔离临时容器破坏恢复演练通过。
- 电子签名使用6位二级密码再认证；首次设置必须复核当前登录密码，修改/审核/发布共享 5 次失败锁定 30 分钟和独立失败审计；签名保存受信代理来源 IP 和密钥版本，绑定记录内容与附件清单摘要，并提供当前/历史密钥验签 API 和前端验真入口。
- 删除、导出、账号启停/授权和选择性共享变更使用 Redis 一次性二级确认 proof；proof 绑定用户、当前会话、HTTP 方法、规范化目标、请求载荷和权限安全戳，5 分钟过期且不可重放；管理员变更目标用户状态或授权后立即撤销其旧会话。
- 科学/产业分类、部门负责人、标签、用户生命周期、角色权限、数据域、字典、界面配置和动态菜单治理；非管理员只能委派自己当前持有且权限不超出自身的角色，权限委派、账号层级、树/引用并发锁、依赖删除、标签规范化、版本 CAS、CSV/XLSX 用户导入和治理审计均已闭环。
- PostgreSQL 空库 V1→V33 及 V9→V31→已发布 V32→V33 遗留升级、Spring 编译、Vue TypeScript 生产构建、Compose/Nginx 合并配置。
